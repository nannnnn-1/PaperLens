# PaperLens 产品需求文档（PRD）

## 1. 产品概述

### 1.1 一句话定位
你的私人学术情报官——帮你高效消费、整理、追踪学术信息。

### 1.2 目标用户
- **核心用户**：理工科研究生（研一~博二），计算机、遥感、地信、AI 方向
- **次要用户**：青年教师、独立研究者
- **排除用户**：本科生（读论文量不够）、资深教授（已有固定信息渠道）

### 1.3 核心闭环
发现论文（推送） → 深度阅读（单篇） → 整理重组（多篇） → 持续追踪（再推送）

### 1.4 明确不做（边界）
- ❌ 不生成论文段落（不写 Introduction/Related Work）
- ❌ 不做通用 PDF 阅读器（不跟 Zotero 抢批注/书签功能）
- ❌ 不做学术社交（关注/点赞/评论）
- ❌ 不做 LaTeX 编译、不做移动端 App（第一版）
- ❌ 不训练自有模型（调用 LLM API 即可）

---

## 2. 设计原则

| 原则                     | 说明                              |
| ------------------------ | --------------------------------- |
| **中英双屏是底座**       | 任何交互只能叠加，不能替换译文区  |
| **Agent 检索兜底**       | 永不显示"未知"，本地→联网→缓存    |
| **人机协同**             | AI 提取，用户纠正，纠正反哺知识库 |
| **每个数字必须有证据链** | 点击即可定位到原文/图表           |
| **空状态必须解释原因**   | 不装傻，不沉默                    |
| **相关度只分两档**       | 高度相关 / 可能相关，不做 5 星    |
| **冷启动不裸奔**         | 预灌核心术语，保证首篇体验        |

## 3. 功能模块

### 3.1 情报推送

#### 3.1.1 早间简报（进货单）
- **触发**：每日 8:00 自动刷新，用户随时可手动刷新
- **内容**：当日 arXiv/顶会新论文，2-3 张卡片
- **卡片元素**：标题、作者、缩略图、AI 速读（2 行）、相关度标签（🔥高度相关 / 💡可能相关）
- **操作**：深度阅读、收藏待读、忽略（5 秒内可撤销）
- **空状态**："今日暂无高度相关论文，说明你的方向还没被卷成红海" + 推荐拓展阅读

#### 3.1.2 晚间简报（日报）
- **触发**：每日 20:00
- **内容形态**：纵向 Newsletter，非卡片货架
- **区块 1：今日阅读统计**（横向三卡片）
  - 阅读数量（大数字 + 论文标题）
  - 互动痕迹（疑问数 / 笔记数 / 纠正数）
  - 时间投入（时长 + 环比 + 连续阅读天数）
- **区块 2：领域热点趋势**
  - 近 7 天论文发布量迷你图
  - 文字洞察（增速、子方向变化）
  - 趋势永远正向解释（变热="风口"，变冷="沉淀期做综述机会"）
- **区块 3：关联推荐**
  - 同作者其他工作
  - 引用今日论文的后续工作
  - 必须解释"为什么推"
- **区块 4：明日预告**
  - 具体事件 + 具体时间（如"CVPR 2026 明早 9:00 更新"）
  - 制造期待，底部快捷入口（待读清单 / 我的图书馆）

#### 3.1.3 兴趣设置
- 手动输入关键词标签（pill 形状，可删除）
- 根据阅读历史推荐补充标签（预留，不强求）
- 推送设置：早间/晚间/即时（默认关）

---

### 3.2 单篇阅读

#### 3.2.1 阅读室底座
- 左右 50/50 分屏，中间可拖拽分隔线
- 左侧：重排版流式原文（章节层级、段落、公式 LaTeX 渲染）
- 右侧：译文（或结构化栏，若原文中文/不翻译）
- 底部：PDF 缩略图导航栏（点击跳原图模式）
- 锚定规则：语义块级同步滚动，当前块轻微高亮

#### 3.2.2 特别标注
- 分类：🔵算法/模型 🟢概念/术语 🟡数据集/指标 🟣引用 🔴代码/工具
- 两侧同步呈现，支持按类别开关
- Hover：0.3 秒浮现轻量气泡（定义 + 出处 + 查看详情 + 库中论文）
- Click：右侧滑出术语详情抽屉（定义、本文使用、原始论文、其他论文使用）

#### 3.2.3 图表卡片
- 流式文本中以卡片插入（占满左栏）
- 元素：缩略图、图注、AI 解读 / 查看原图 / 提问 三按钮
- 查看原图：弹出 Overlay，高清缩放，扫描版显示 OCR+原图对照

#### 3.2.4 选中再聊（核心交互）
- 选中文字 → 淡蓝高亮 → 上方浮现工具栏（💬提问 📝笔记 ⭐收藏）
- 点击提问 → 底部对话抽屉升起
- 对话自带上下文（选中文字 + 邻近段落 + 标注信息）
- 多轮追问，上下文锁定
- 回答底部：✓ 有用 / ✕ 纠正

#### 3.2.5 大纲导航
- 左侧滑出章节树，当前章节蓝色高亮填充
- 章节标题下方悬浮速览卡片（可折叠）

#### 3.2.6 论文理解档案（阅读后沉淀）
- 自动归档：方法卡片、Q&A 历史、笔记、收藏、Agent 行为日志
- 关联网络：渐进构建（引文关系、方法继承）

---

### 3.3 多篇整理

#### 3.3.1 项目空间
- 左侧边栏：论文列表 / 对比矩阵 / 方法演进 / 项目问答 / 项目设置
- 默认页：论文卡片列表（缩略图 + 标题 + 方法标签 + 速览）

#### 3.3.2 对比矩阵
- 预设列（基于领域惯例）：年份、论文、方法、骨干网络、数据集、mIoU、速度、监督方式
- **Agent 自定义列**：自然语言描述需求，Agent 理解后添加（如"代码开源""参数量"）
- 单元格可点击 → 右侧证据抽屉（定位原文/图表/原图）
- 系统主动检测数据矛盾（同一论文不同位置数值冲突）
- 空单元格解释原因（不是留空）
- 用户纠正：双击编辑 / 证据抽屉选择正确值
- 导出：CSV / Markdown / PNG

#### 3.3.3 方法演进
- 横向时间线，节点为方法卡片，连线带改进标签
- 第一版按时间线固定排列，不支持拖拽（后期优化）
- 点击节点 → 方法详情；点击连线 → 对比分析

#### 3.3.4 项目问答
- 范围锁定：顶部提示"基于本项目 N 篇论文"
- 自由输入，多轮追问
- 回答中每个事实带引用上标 `[n]`，点击定位原文
- 可临时切换"全网模式"（项目内实线框，外部虚线框）

## 4. 用户旅程（小明的故事）

### Day 1：首次使用
1. 注册 → 设置兴趣标签（遥感变化检测、半监督、Mamba）
2. 系统预灌冷启动数据，保证首篇体验

### Day 2：早间
1. 打开 PaperLens → 进入早间简报
2. 看到 2 篇新论文，收藏 1 篇，深度阅读 1 篇
3. 深度阅读：进入阅读室，翻译、标注、图表、问答
4. 自动生成论文理解档案

### Day 2：晚间
1. 打开 PaperLens → 进入晚间简报
2. 查看今日阅读统计、领域趋势、关联推荐、明日预告

### Day 5：整理
1. 图书馆多选 5 篇 → 创建「变化检测课题」项目
2. 查看对比矩阵：预设列 + 自定义列（代码开源、参数量）
3. 纠正 BIT 速度数据，查看证据链
4. 导出 Markdown 对比表，贴进组会汇报

### Day 6：持续
1. 早间简报再次推送，新论文显示"引用了你已读的 RS-Mamba"
2. 循环

## 5. 技术架构

### 5.1 语言分工
- **前端**：React 18 + TypeScript + Vite（桌面端优先）
- **业务后端**：Node.js + TypeScript + Express/Nest.js（用户、文件、任务、推送）
- **AI 服务**：Python + FastAPI（PDF 解析、LLM 调用、向量检索）
- **通信**：业务后端 ↔ AI 服务通过 HTTP/gRPC

### 5.2 存储
- PostgreSQL：业务关系数据 + PGVector（向量检索，前期）
- MongoDB：文档原文、大文本
- Redis：缓存、任务队列、会话
- MinIO/OSS：PDF 文件、图表截图

### 5.3 关键数据流
1. 用户上传 PDF → 业务后端存 OSS → 写 DB（状态 UPLOADED）→ 发 Job 到 Redis
2. Python Worker 消费 Job → 解析（文本/图表/表格）→ 生成方法卡片/向量/术语
3. 回写 PostgreSQL → 通知前端 → 状态变为 READY
4. 用户 Hover 术语 → 业务后端查本地库 → 未命中则调 AI 服务检索 → 缓存 Redis

## 6. 非功能需求

### 6.1 性能
- Hover 气泡 500ms 内响应（骨架屏优先）
- 单篇 PDF 解析 &lt; 30 秒（8 页论文）
- 页面首屏加载 &lt; 2 秒

### 6.2 成本
- 单篇论文完整处理成本：¥0.5-2.0（LLM API）
- 免费版：每月 10 篇上传 / 3 篇免费处理
- 付费版：¥15/月 ≈ 20-30 篇预算

### 6.3 安全与隐私
- 论文内容不上传用于训练（明确承诺）
- 支持删除（物理删除 OSS + 逻辑删除 DB）
- 未发表论文上传时，建议用户确认隐私风险

## 8. 术语表

| 术语         | 定义                                                         |
| ------------ | ------------------------------------------------------------ |
| 方法卡片     | 从论文中提取的标准化知识单元：方法名 + 数据集 + 指标 + 实验设置 |
| 论文理解档案 | 单篇阅读结束后自动生成的归档：方法卡片 + Q&A + 笔记 + Agent 日志 |
| 语义块       | 原文-译文锚定的最小单位（段落级或句级）                      |
| 证据抽屉     | 点击对比矩阵单元格后滑出的面板，展示数据来源和原文定位       |
